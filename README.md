# heisty-clips

Social video for [Heisty](https://heisty.games), the daily heist puzzle.

## Layout

- Dated folders (`2026-W46/`, `2026-11-06-vault/`, `2026-11-09-crown-race/`)
  hold finished clips plus a `captions.md` with the post text, hashtags,
  puzzle links and answers for that batch.
- `remotion/` holds the source for the videos built as code (brand and
  campaign pieces). See its README to preview or re-render.

Puzzle links in captions work where links are clickable (Discord, X, Threads,
Reddit). On TikTok, Reels and Shorts they are not, so the bio points at
heisty.games.
